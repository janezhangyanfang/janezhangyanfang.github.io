Virtual Object Wind Clock

The virtual object wind clock is a small and refreshing mobile desktop clock. The virtual object wind clock is a custom editor that displays your favorite desktop clock.

-Displayed on the main screen in seconds.

-Display time, display year month day, display week

-12 and 24-hour modes

-Support multiple custom themes

-Support multiple modes of simulated object wind

-Supports multiple flash modes, such as wave lights, flashing lights, heart lights, and more.
